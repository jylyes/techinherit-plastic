# techinherit 材料分站

蓝白配色的静态多页网站。定位为 techinherit 的**材料业务分站**，借鉴融塑网站的页面结构与交互节奏，内容按 techinherit 官网材料目录重新整理。

## 打开方式

直接双击 `index.html` 即可打开。所有 CSS、JavaScript、照片和占位素材均为本地文件，无框架、构建步骤、远程字体或接口依赖。

通过本地静态服务器预览也可以。本站未发布到公网。

## 页面范围

共 66 个中文页面，以及 `en/` 目录下逐页对应的 66 个英文页面（合计 132 页）：

- 首页 `index.html`。
- 公司概况：`about.html`、`culture.html`、`quality.html`、`gallery.html`。
- 材料中心：`products.html`、`compare.html`，以及 `materials/` 中 37 个材料详情。
- 研发探索：`research.html`、`technology.html`、`process.html`。
- 应用领域：`applications.html`，以及 `applications/` 中 6 个应用详情。
- 材料资讯：`news.html`、`faq.html`，以及 `insights/` 中 8 篇选型笔记。
- 联系与支持：`contact.html`、`service.html`。

## 文件与修改

| 文件 | 用途 |
| --- | --- |
| `styles.css` | 首页与全站基础样式，顶部 `:root` 为蓝色主题变量 |
| `pages.css` | 内页布局、材料卡片、筛选、对比、表格、FAQ 与联系表单 |
| `catalog.js` | 材料、分类、应用、文章摘要、问题和官网来源的数据 |
| `catalog-en.js` | 英文材料、应用与资讯数据，保留中文搜索别名 |
| `site.js` | 全站导航、搜索、筛选、分页、对比、图片预览、咨询草稿 |
| `script.js` | 首页轮播、图库拖动与品牌动态概念展示 |
| `site-en.js` / `script-en.js` | 英文版对应交互与提示 |
| `language-switch.js` | 对应页面切换，保留查询参数与锚点 |
| `en/` | 66 个英文 HTML 页面，与根目录中文版一一对应 |
| `locales/en.json` | 英文翻译对照记录 |
| `assets/` | 本地图片与素材 |
| `assets/materials/` | 37 项材料对应的官网图片、大图与缩略图；`sources.json` 记录原始地址 |
| `assets/applications/` | 六个应用领域的 AI 生成场景图；`generation-prompts.json` 保存完整提示词 |
| `engineering.css` | 材料性能、研发证据、案例与对比模块的共用样式 |
| `content/material-reference-data.json` | 37 项材料的官网原文参数与来源日期记录 |
| `content/application-case-notes.json` | 12 个官网零件案例的材料分析、关联方向与来源 |
| `assets/research/`、`assets/cases/` | 官网研发及零件配图；来源见 `assets/upgrade-photo-sources.json` |

HTML 文件包含静态正文，便于直接修改和浏览。若修改材料数据，需同步修改对应详情页中的静态正文，确保列表与详情一致。

当前以根目录中文页面为编辑入口，英文页面位于 `en/` 的同名路径。英文 HTML 与数据均为本地文件，不调用在线翻译接口；修改中文后，需同步更新对应英文正文或翻译数据。

## 已接通的交互

- 首页、桌面下拉菜单、手机菜单、面包屑与页尾进入真实内页。
- 37 项材料按类别、基体树脂或关键词组合筛选，含分页与无结果状态。
- 最多三项材料对比；支持跨页保留选择、移除、清空和直接链接。
- 对比页可用下拉框选择材料，并将所选材料带入咨询。
- 材料详情提供概览、资料说明、相关推荐、前后材料导航和选型记录下载。
- 全站搜索包含材料、分类、应用、文章和主要栏目。
- 应用详情关联相关材料；资讯分类、关键词和分页；FAQ 分类搜索及原生展开。
- 图片分类、图库与放大预览，支持键盘关闭及切换。
- 联系表单预填材料或需求，校验后可复制需求或打开邮件草稿。
- 默认打开中文版。顶部圆圈 EN 切换到本站对应英文页面；英文版圆圈“中”返回对应中文版，保留查询参数、章节锚点与材料对比选择。
- 中英文材料目录、搜索、筛选、对比、FAQ、咨询草稿和首页交互均可使用。导航继续停留在所选语言中。
- 左上角和页脚使用 techinherit 官网图形 logo；页脚背景为官网同款 `#121a24`，标题白色、链接灰色。

## 内容依据与边界

材料名称与业务方向参考 https://www.techinherit.com/raw-materials.html 及其目录，来源整理日期：2026-10-23。每个材料条目的官网地址存于 `catalog.js` 的 `source` 字段。

主站材料目录中的个别条目位于名称与内容不一致的旧目录路径下；本分站按材料本身归类，并保留其来源地址。

材料详情和对比页于 2026-10-24 补入官网公开参考信息，共整理 595 个参数字段，其中 458 个有有效公开数值，覆盖 28 项材料；另外 9 项的公开数值仍待补充。数值与原文条件、来源链接同时展示，不能视为具体牌号的正式 TDS 或同一测试条件下的数据。未虚构测试标准、认证、牌号或检测结果。PA6 / PA66 通用页中一项模具温度的原文字段与数值存在疑义，已排除为工艺建议并标注待核对。

8 篇资讯为围绕官网材料主题重新撰写的选型笔记，标注内容整理日期，不冒充原站新闻全文或原始发布日期。

研发／空间页已改用官网研发页面展示的 5 张配混、灼热丝试验、测量和材料样品照片，保留来源入口。公司简介及首页研发、空间区块同步替换相关占位图。设备、能力与测试范围依据官网说明整理，具体标准、设备适用范围及报告形式仍按项目核对。品牌视频仍为动态概念占位。

应用列表和六个领域详情横幅使用内置 imagegen 生成的场景图，保留原始 1672×941 分辨率，六张合计约 0.94MB；这些是应用示意图。详情正文新增 12 个官网零件案例，每个案例包含官网零件配图、公开材料体系、应用问题和建议验证重点，并链接官网来源。未迁移无法核对的良率、认证或性能提升结论；目录材料仅为相关方向，不直接代替案例专用牌号。原始场景 PNG 和提示词另存于交付图片包。

材料图片于 2026-10-23 从 techinherit 官网材料目录下载，37 项材料共对应 33 张独立原图，保留官网的图片匹配关系。首页六类材料、材料列表、详情及相关推荐均已使用本地官网图片。详情图片可点击放大。

列表使用最大 400px 的缩略图，详情大图最长边最大 900px，保留原始比例并按需加载。33 张原图合计约 6.86MB；优化后的大图合计约 2.20MB，缩略图合计约 0.64MB。图片替换可从 `catalog.js` 的 `officialImages` 对应条目调整，来源记录见 `assets/materials/sources.json`。

下载的 `.txt` 是选型／对比记录，**不是 TDS、SDS、测试报告或认证文件**。

对比页新增力学、热与阻燃、电气、加工分类和“只看不同项”，筛选状态通过 URL 保留；记录下载包含完整参考参数、条件与来源。材料详情提供性能和工艺表、验证关注点、应用关联及资料咨询。默认仍为中文，中英文同步。

## 性能与适配

- 保留上一轮优化：原生滚动、没有逐帧背景视差、固定导航不使用背景模糊。
- 首屏与地图离开可视区后暂停循环动画；滚动入场每个区块只播放一次。
- 本地 WebP 图片、异步解码、非首屏图片延迟加载。
- 顶部字标采用与官网一致的本地 Roboto 字体，保留字体许可；与首屏文案左边缘对齐。透明状态为白字，滚动、悬停及菜单展开后为深色字标。
- 首页第一张使用官网 `factory.webp` 原始文件，保存在 `assets/hero-corporate-original.webp`，未重新压缩且取消额外缩放；官网提供的该图为 900×522。第二张为原先的实验室图片。
- 首页两张轮播图统一使用官网同款 135° 蓝黑渐变遮罩，移除了原有的青灰色及底部叠加压暗层。
- 响应式桌面／手机布局、原生弹窗、键盘操作及减少动态效果适配。
- `localStorage` 不可用时不阻断页面；对比链接通过 URL 传递材料 ID，对比页仍可手动选择。
