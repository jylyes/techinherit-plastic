# Techinherit Materials

Techinherit 材料业务分站。静态多页网站，由 GitHub Pages 从 main 分支发布。访客访问时不调用在线翻译服务。

网站：https://jylyes.github.io/techinherit-plastic/

## 语言与页面

默认英语，英文主站位于根目录；en/ 保留原有英文链接。中文 zh/、越南语 vi/、泰语 th/、印尼语 id/、印地语 hi/、韩语 ko/、日语 ja/。右上角语言菜单支持同页切换，保留分类查询参数和章节锚点。

每种语言有 117 页：14 个主要栏目、89 个材料详情、6 个应用详情和 8 篇材料笔记。八语言共 936 页，另保留 117 个英文兼容页面，总计 1,053 个 HTML 文件。

## 材料与交互

目录含透明尼龙12、长碳链尼龙、生物基尼龙、导电防静电材料、碳纤维复合材料和行业专用材料六类，去重后共 89 项。同一材料可属于多个分类。

- 按材料类别浏览并分页，支持详情、性能参考、相关材料和咨询。
- 已移除全站搜索入口、材料关键词与基体筛选、材料对比功能及页面。
- 资讯和 FAQ 保留各自的栏目检索功能。
- 首页轮播在鼠标悬停时继续播放，支持手动暂停、键盘和触摸操作。
- 支持图片放大、图库分类、移动端导航和八语言菜单。
- 咨询表单生成本地草稿，可复制或打开邮件客户端；没有后台提交接口，不代表已经发送。

## 文件与维护

- styles.css、pages.css、engineering.css：共用样式。
- language-menu.css、language-switch.js：语言菜单和同页切换。
- catalog.js、site.js、script.js：中文数据和交互；其他语言使用对应语言后缀。
- locales/：翻译词典；英文词典以中文为键，新增语言词典以英文为键。
- content/：材料目录、行业方案、参考资料、图片计划和语言清单。
- assets/：共用图片、字体和图标。

可直接打开 HTML 或使用静态服务器预览。常用材料术语和树脂代号已统一，新增语种的长篇技术文案建议在正式推广前做母语校对。
