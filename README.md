# techinherit 材料分站

蓝白配色的静态多页网站。定位为 techinherit 的**材料业务分站**，采用完整的多页栏目结构，连接材料目录、应用与咨询。

## 打开方式

直接双击 `index.html` 即可打开。所有 CSS、JavaScript、照片和占位素材均为本地文件，无框架、构建步骤、远程字体或接口依赖。

通过本地静态服务器预览也可以。线上网址：https://jylyes.github.io/techinherit-plastic/ 。127.0.0.1:4173 仅为本机预览，需要保持本机预览服务运行。

## 材料目录（2026-10-24）

按当前业务展示需求，暂时移除工程塑料、玻纤增强材料、功能改性材料及热塑性弹性体四类，共 19 项材料及其中英文详情页面。当前展示透明尼龙12（5 项）、长碳链尼龙（5 项）、生物基尼龙（3 项）、导电防静电材料（61 项）、碳纤维复合材料（11 项）及行业专用材料（7 项），去重后共 89 项；导航、首页、搜索、筛选与对比同步调整。应用案例中有来源的历史材料说明保留，已移除指向下架材料的链接；历史图片仍保留以便后续调整。GitHub Pages 使用 main 分支自动发布，更新仓库后可在线核对发布结果。

## 页面范围

共 118 个中文页面，以及 `en/` 目录下逐页对应的 118 个英文页面（合计 236 页）：

- 首页 `index.html`。

- 材料资讯：`news.html`、`faq.html`，以及 `insights/` 中 8 篇选型笔记。

当前以根目录中文页面为编辑入口，英文页面位于 `en/` 的同名路径。英文 HTML 与数据均为本地文件，不调用在线翻译接口；修改中文后，需同步更新对应英文正文或翻译数据。

## 已接通的交互

- 首页、桌面下拉菜单、手机菜单、面包屑与页尾进入真实内页。

- 应用详情关联相关材料；资讯分类、关键词和分页；FAQ 分类搜索及原生展开。
- 图片分类、图库与放大预览，支持键盘关闭及切换。
- 联系表单预填材料或需求，校验后可复制需求或打开邮件草稿。
- 默认打开中文版。顶部圆圈 EN 切换到本站对应英文页面；英文版圆圈“中”返回对应中文版，保留查询参数、章节锚点与材料对比选择。
- 中英文材料目录、搜索、筛选、对比、FAQ、咨询草稿和首页交互均可使用。导航继续停留在所选语言中。

## 性能与适配

- 保留上一轮优化：原生滚动、没有逐帧背景视差、固定导航不使用背景模糊。
- 首屏与地图离开可视区后暂停循环动画；滚动入场每个区块只播放一次。
- 本地 WebP 图片、异步解码、非首屏图片延迟加载。
- 顶部字标采用与官网一致的本地 Roboto 字体，保留字体许可；与首屏文案左边缘对齐。透明状态为白字，滚动、悬停及菜单展开后为深色字标。
- 首页第一张使用官网 `factory.webp` 原始文件，保存在 `assets/hero-corporate-original.webp`，未重新压缩且取消额外缩放；官网提供的该图为 900×522。第二张为原先的实验室图片。
- 首页两张轮播图统一使用官网同款 135° 蓝黑渐变遮罩，移除了原有的青灰色及底部叠加压暗层。
- 响应式桌面／手机布局、原生弹窗、键盘操作及减少动态效果适配。
- `localStorage` 不可用时不阻断页面；对比链接通过 URL 传递材料 ID，对比页仍可手动选择。
